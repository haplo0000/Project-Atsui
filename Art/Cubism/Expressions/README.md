# Cubism / Expressions

Live2D expression files (`.exp3.json`).

Map expressions to app modes and emotional states. Minimum set:

- Neutral / idle
- Analytical focus
- Professional formal
- Playful / gaming
- Intense / battle
- Synthetic / AI processing
- Sleepy / dormant
- Strained / overheated

Naming: `atsui_<expression>.exp3.json`
