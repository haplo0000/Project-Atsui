# Cubism / Motions

Live2D motion files (`.motion3.json`).

## Required motions (minimum)

| File | Purpose |
|------|---------|
| `atsui_idle.motion3.json` | Default idle loop |
| `atsui_blink.motion3.json` | Blink cycle |
| `atsui_breathe.motion3.json` | Breathing cycle |
| `atsui_mode_transition.motion3.json` | Mode change accent |

Additional mode-specific motions may be added per milestone.
