# Cubism

Live2D Cubism Editor project workspace for the Atsui avatar rig.

## Subfolders

| Folder | Contents |
|--------|----------|
| `Models/` | `.cmo3` model project files |
| `Motions/` | `.motion3.json` animation clips |
| `Physics/` | `.physics3.json` physics settings |
| `Expressions/` | `.exp3.json` facial expressions |
| `Exports/` | Staging area for Cubism Editor exports |

See [`../Docs/PIPELINE.md`](../Docs/PIPELINE.md) for the Live2D workflow.
