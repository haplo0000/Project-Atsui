# Exports

Build-ready artwork outputs for engineering handoff.

## Subfolders

| Folder | Purpose |
|--------|---------|
| `Runtime/` | Files wired into the application |
| `Textures/` | Individual layer PNGs before runtime promotion |
| `Archives/` | Versioned zip snapshots and `VERSION.txt` |

See [`../Docs/PIPELINE.md`](../Docs/PIPELINE.md) for the export workflow.
