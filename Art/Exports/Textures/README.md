# Exports / Textures

Intermediate layer exports from PSD slicing before runtime promotion.

Use this folder to stage and review individual layer PNGs. Promote validated files to `Runtime/` after QA.

Expected properties:

- Transparent background
- Consistent canvas dimensions across all layers in a set
- @1x base: 200×240 or @2x: 400×480 (document chosen scale in `Archives/VERSION.txt`)
