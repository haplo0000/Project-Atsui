# Master

Canonical visual reference for the Atsui character.

This folder is **not** consumed at runtime. It is the visual source of truth for artists and riggers.

## Subfolders

| Folder | Purpose |
|--------|---------|
| `Approved/` | Lead-approved master sheets only |
| `Concepts/` | Work-in-progress exploration |
| `References/` | External refs, mood boards, pose sheets |
| `ColorPalettes/` | Per-mode color swatches |

See [`../Docs/PIPELINE.md`](../Docs/PIPELINE.md) for naming and approval workflow.
