# Templates

Pipeline templates, manifests, and helper scripts for the Atsui art pipeline.

## Contents

| Item | Purpose |
|------|---------|
| `layer-export-manifest.template.json` | Per-export JSON checklist |
| `scripts/validate-art-structure.mjs` | Verify folder structure |
| `scripts/validate-naming.mjs` | Verify runtime file naming |
| `scripts/update-version.mjs` | Bump `VERSION.txt` fields |

No final artwork belongs in this folder.
